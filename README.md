# Beamlet

> A Powerful Agent.

**WIP**, with broken changes before the first release.

## Build

```bash
# Development shell
nix develop

# Package
mix local.hex
mix deps.get
mix deps.update --all

# Format
mix format

# Compile
mix compile

# Test
mix test
```
