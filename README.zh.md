# Beamlet

> 一个强大的 Agent

**WIP**, 在首个 Release 前可能存在破坏性更改

## 构建

```bash
# 开发环境
nix develop

# 包管理
mix local.hex
mix deps.get
mix deps.update --all

# 格式化
mix format

# 编译
mix compile

# 测试
mix test
```
