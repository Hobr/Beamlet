# Beamlet 领域术语

本术语表统一通用运行时及其使用方的领域语言。实现选择应记录在设计与规范中。

## 术语

**计算定义（Computation Definition）**：
根据输入推进应用状态的一组版本化规则。
_避免混用_：Agent 定义、进程映像。

**运行实例（Run）**：
某个计算定义的一次运行，具有独立标识、状态与历史。
_避免混用_：PID；描述通用运行时时的“会话”。

**能力调用请求（Invocation）**：
应用层对某项能力操作的请求，包含参数与回复键。
_避免混用_：面向业务的请求不应称为 Effect。

**持久化操作（Effect）**：
一个逻辑操作，其不可变意图被持久化，执行过程与结果受到跟踪。
_避免混用_：Attempt、Cordis 注册副作用、Ra 调度副作用。

**执行尝试（Attempt）**：
授予一个执行主体执行某个 Effect 的一次独立权限，具有自己的绑定、证据与观测结果。
_避免混用_：单次重试或执行授权不应称为 Effect。

**执行主体（Execution Owner）**：
承接一次执行尝试的特定工作进程实例。替代或重启后的工作进程是新的执行主体。
_避免混用_：执行节点；可在重启后重新占用的服务名称。

**操作结果（Outcome）**：
关于操作完成情况的观测或显式裁定。结果未知不代表尚未执行。
_避免混用_：执行结果未知时，不应称为“失败”。

**不确定性通知（Uncertainty Notification）**：
告知计算某项调用尚无终局结果的输入。消费该通知不代表操作已经完成。
_避免混用_：终局回复、已确认失败。

**调用裁定（Invocation Resolution）**：
对未决调用追加证据、确定终局结果或明确允许再次执行的决定。
_避免混用_：执行前审批、外部操作撤销。

**能力（Capability）**：
在某个 Scope 内可用的稳定操作契约。
_避免混用_：节点、具体提供者。

**提供者（Provider）**：
能力操作的实现，能够访问这些操作所需的资源。

**作用域（Scope）**：
定义能力可见性、选择、配置和生命周期关系的上下文。
_避免混用_：安全沙箱。

**资源引用（Resource Reference）**：
稳定的逻辑资源引用，附带适用的标识或匹配约束。
_避免混用_：运行时资源句柄。

**权威域（Authority Domain）**：
由指定权威组确定 Run 权威历史的范围。
_避免混用_：仅指存储权威节点时，不应称为整个 BEAM 集群。

**存储权威节点（Storage Authority）**：
用户指定的、参与权威持久化的节点。

**计算宿主（Computation Host）**：
被指派依据计算定义推进某个 Run 的节点。

**执行节点（Execution Node）**：
能够提供资源并执行能力操作的节点。

**稳定边界（Stable Boundary）**：
已提交的应用状态点，相关 Effect 及其完成结果投递均已处理完毕。

**历史前缀（History Prefix）**：
与选定边界关联的历史，包括已完成操作的结果。

**分支（Branch）**：
从另一个 Run 的稳定边界派生出的 Run，后续工作具有独立标识。

**派生关系（Lineage）**：
连接各 Run 及选定分支边界的来源关系。

**暂停（Suspension）**：
一种持久化模式，阻止新的状态推进和执行授权，同时保留已获授权工作的结果。
_避免混用_：外部操作取消。

**计算归档（Computation Archive）**：
稳定边界、其数据与历史，以及兼容性要求的可移植表示。
_避免混用_：进程转储、外部环境快照。
