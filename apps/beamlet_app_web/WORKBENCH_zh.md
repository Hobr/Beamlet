## 任务与活实例

先显式启用 Host 与受信目录。`/` 提供任务入口和发现，`/agents/new` 展开选项，`/agents/:handle` 打开精确活实例。选择预设应用默认值，调整与重置仅影响新实例；无相关工具需求时清空环境选择。缺目录时停用创建，不探测提供方或寻找回退。

发现包含本地身份及允许列表中当前已连接的远端，不隐式连接或扫描所有 Node.list 节点。本地 not_authority 是已知无 authority，其他失败保留为不完整；complete 仅描述本地与已配置已连接范围，不是全部配置节点或原子集群快照。浏览器随机键选择服务端保存的精确描述符，不把 PID 或 atom 编入可解码身份。打开时重核 incarnation，同名替换须重新发现。

创建调用者 UI 截止 16 秒，普通命令/读取通常 8 秒。身份、确认 Ref、输入里程碑与最终结果经同一守护者顺序传递；待处理锁阻止重复事件，代际/命令/选中 Ref 检查屏蔽旧回复。创建、初始输入、导航三项结果分别呈现。截止或调用者死亡不撤回排队的本地创建，不取消外部副作用；未知结果须按显示身份显式发现，禁止自动重发/替换。已确认实例在输入/导航失败时仍保留。后端 busy 与限制是最终依据，执行中的草稿不是队列。

## 观察所有权与显示

只订阅选中的 Agent。观察守护者拥有关联 sink 并监控页面，切换先等旧守护者 DOWN 才订阅。sink 发出一个替换快照，待 LiveView 消费后由同一 sink ack，保留源 credits/coalescing。离开请求退订，必要时六秒后杀死 sink 并等待实际退出；Agent 不因观察清理关闭。发送退出请求不等于观察到退出。

离开页面只退订，stop 停当前轮次并保留实例，close 需要单独确认；都不证明外部效果已回滚。子 Agent 查看默认为只读，并有事件端守卫。源丢失/远端不可用表示结果未知，不显示为成功停止/关闭。

页面以转义纯文本显示保留上下文、源轮次边界、当前并发活动及省略/截断。引用转换为不透明关联标签，不从到达顺序猜测轮次。快照整体替换；请求的 display 缺失会清空旧显示。完成活动可能消失，未知执行位置保持未知；不宣称完整历史、token 流、推理记录、归档或重放。私有配置、凭据与 PID/Ref 结构不渲染。DOM 滚动 hook 只保存滚动状态：读者不在底部时提示新活动，不强制滚动；无 localStorage 转录。

重启清空导航；远端存活实例可重新发现，嵌入 authority 重启可能丢失自己的活实例。安全边界见 [宿主说明](HOST_zh.md#临时导航与部署边界)。

## 只读管理

| 页面 | 范围与限制 |
| --- | --- |
| `/admin/nodes` | 显式本地与配置的受信目标，经公开 Node.observe 读取；不连接节点 |
| `/admin/presets` | 与创建表单相同的 Presets.describe 安全投影，无私有解析值或修改表单 |
| `/admin/diagnostics` | 精确 handle 的实时观察，activity 参数仅选择当前关联标签，失效不重建历史 |

管理页面只响应 refresh，伪造 input/stop/close/connect/restart/write-config 等事件忽略。单个页面一次读取，页面截止 12 秒；底层最多 32 目标/8 worker/五秒/1 MiB。含本地后超过范围的目标显式显示未读/未知。无通用 RPC、终端、日志查询、追踪收集器、恢复、配置写入或持久诊断。

连接状态、角色配置、服务注册就绪与 Runtime 报告新鲜度分开呈现。注册存在不证明响应性或提供方健康；not_reported/stale 不证明节点死亡。年龄由报告源计算，不跨 VM 相减单调时钟；available 是建议可用量，总容量与利用率未知，不跨 endpoint 求和。未配置/空列表等已知缺失与未知事实须区分。失败保留上次观测、接收时刻与动作专属原因，并声明当前事实未知，不呈现健康空页。

诊断页复用共享活动组件并禁用子项命令，只提供回到工作台观察的页面级链接；工作台活动卡可深链到诊断。诊断页不提供逐活动或逐错误深链接。导航不是授权。

## 语言与会话

默认简体中文 zh_CN，支持 en。有效 `?locale=` → 签名会话 locale → 应用 default_locale → 共享 zh_CN。规范化接受 zh/zh-cn/zh_CN/cn 与 en/en-us/en_US，未知值不写回会话。请求 plug 与 LiveView on_mount/on_params 安装当前进程语言。

语言链接保留页面路径，完整页面载入使选择写入签名 cookie；既有渲染文本在下次页面载入前保持原语言，无客户端重新翻译。cookie 只携带非敏感语言偏好，无数据库/浏览器存储。公共词归 I18n，Web/CLI 专用词归各自目录，一个 msgid 只拥有一次。缺译文回退英文 msgid；业务标识和命令语法不翻译。语言不影响 Agent/Node/Runtime 行为。
