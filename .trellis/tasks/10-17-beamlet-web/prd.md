# Beamlet Web 通用 Agent 工作台与管理页面

## Goal

让用户在不理解 BEAM 集群细节的情况下，以任务和 preset 创建持续交互的通用 Agent，看懂真实执行过程并明确控制其生命周期；另提供只读管理视图解释配置、节点与运行问题。

## Background and Confirmed Decisions

- 用户在本次会话逐项确认：面向用户的通用工作台而非编码专用产品；附带管理页面；不实现多用户，企业可自行集成身份与授权。
- 创建入口为任务优先，preset 是可调整的配置起点，不是 Agent 子类或工作流。Agent 是持续多轮交互的对象，一个 turn 对应一次任务。
- 最终指示：“同意相关设计，创建任务，暂时不需要持久化和数据库”。之前关于历史/恢复的讨论只是未来产品方向，本阶段不以 UI 存储补实现。
- 当前 Web 是 Phoenix 骨架；Agent/Node 已具备显式生命周期和有界存活发现，但快照缺少完整显示投影，节点缺少公共产品观测接口。事实与源码锚点见 [current-capabilities.md](research/current-capabilities.md)，技术方案见 [design.md](design.md)。
- 用户已在最终规划摘要之后回复“批准”（2026-10-17），授权按文档顺序进入实现。父任务保留集成职责，从 `10-17-web-observation` 子任务开始；其余子任务依次满足前置验收后启动。

## Requirements

### R1 — 通用、单可信空间

用户进入的是通用 Agent 工作台，不必先选择代码项目或理解节点角色。一个实例是共享可信空间，不存在私人 Agent、账号、组织、租户、RBAC 或用户级资源归属。管理入口只是视图分区，不伪装为权限边界；非本机暴露需要部署侧访问保护。

### R2 — 任务优先和可调整 preset

用户输入任务、选择 preset，检查能力摘要后即可创建并开始；可展开调整模型、工具、必要环境、名称和高级选项。只有需要环境的能力才要求环境。调整只影响本次创建，支持恢复默认，不自动覆盖原 preset 或修改既有实例。模型绑定的不可变限制可见；不能伪装成运行时换模型。

### R3 — 配置与能力边界真实有效

仅允许选择部署实际配置的模型、工具、环境和 authority。前端伪造参数不能扩展工具/环境范围、加载模块或取得凭据。工具在创建时明确的范围内自主执行，不加入逐次审批。风险摘要展示写入/命令等实际能力；不存在的工具或隔离能力不作为可用功能宣传。

### R4 — 创建与首次输入的独立结果

创建和初始任务输入不是原子动作。创建成功但输入失败时保留该实例和继续入口；超时/断线导致结果未知时明确不确定性，不自动重发、创建替代实例、切换 authority 或回退模型。

### R5 — 查找、重新附着与身份

列表、搜索及点击打开可发现存活 Agent，包括 CLI 创建的实例。多 authority 同名可区分；查询不完整、不可达和未找到可区分。列表与打开间发生实例替换时不静默附着新实例。浏览器和 CLI 不是 Agent 生命周期所有者。

### R6 — 连续交互与有界真实观测

工作区为 Agent 列表、带 turn 分界的连续对话、可折叠工具/委派活动及按需检查面板。进度、参数、结果、错误及执行位置只展示可观察事实，未知即未知；不伪造 token 流、内部思考或完整轨迹。当前内存上下文/活动可安全投影，过大内容明确截断；订阅合并/遗漏不包装成事件历史。桌面与小屏可用，长输出不撑坏页面，用户阅读旧内容时不强制滚动。

### R7 — 明确控制和并发冲突

离开/切换/断线只清理观察；停止当前任务不关闭 Agent，关闭实例是独立确认动作。停止请求不等于远程工作确认终止或外部副作用撤销。运行中允许输入草稿但不隐式排队或插话；多标签页/CLI 的 busy、stale、unavailable 和不确定结果可见。

### R8 — 独立只读管理视图

提供节点、preset/能力配置与当前运行诊断。区分连通、服务就绪、报告新鲜度；展示真实可用容量，不编造容量总数或资源隔离保证。用户错误可跳转到共享诊断面板。管理侧不做在线配置写入、任意 RPC/终端、节点重启、角色热切换或业务恢复。

### R9 — 无持久化、数据库与恢复

不新增数据库、ORM/Repo/migration、持久工作记录、文件或浏览器 transcript、归档、重放及 durable action 实现。刷新/重连只观察存活实例的当前可用上下文；历史不完整应提示。Web 临时导航状态可丢失，authority 丢失后不重建实例。Web 自带 authority 时其重启可能丢失 Agent；远程存活 Agent 可重新发现，不等于恢复失效 Agent。

### R10 — 共享接口、隔离与安全

Web 复用库级 Agent/Node/Runtime 契约，不读私有进程状态、不复制调度器、不依赖 daemon/CLI。普通应用加载与测试不意外启动角色、连接集群或调用真实 provider。模型配置/凭据、工具根目录、私有状态和原始异常不进入页面、URL、可读 cookie 或日志。保留 CSP/CSRF、开发诊断门控与已有库/宿主语义。

## Acceptance Criteria

- [x] AC1/R1,R2：从首页任务输入选择/调整 preset 完成创建；无工具对话不要求环境；配置差异与风险可见，原 preset 与既有 Agent 未变化。
- [x] AC2/R3,R10：未知/伪造模型、工具、环境、authority 或原始配置被安全拒绝；真实工具只能访问已配置范围；页面/URL/session/log 中无预置测试凭据或工具根配置。
- [x] AC3/R4：确定的创建成功/输入失败保留同一实例；模糊确认显示未知且没有业务重试或重复创建。
- [x] AC4/R5：Web 与 CLI/第二观察者发现并附着同一存活实例；同名、实例替换、部分列表及节点断线都有不同可见结果，旧入口不重绑。
- [x] AC5/R6：确定性模型→工具→模型任务展示真实输入/输出/活动，之后能在同一 Agent 继续新 turn；长上下文/活动截断可见且不改变模型上下文；慢订阅不失控。
- [x] AC6/R7：离开页面不停止 Agent；停止 turn 后实例保留，关闭才结束；busy/停止不确定性与观察断线独立呈现，运行中不隐式排队。
- [x] AC7/R8：节点页覆盖可达但未就绪、不可达、无报告、报告失效及部分结果；preset 页是可信配置投影，诊断可关联已有身份，管理无写入/终端/热配置入口。
- [x] AC8/R9：依赖与文件审查证明未新增数据库或持久存储；Web 重启后仅通过新发现打开仍存活的远程实例；失效实例/缺失历史没有恢复、重放或归档假象。
- [x] AC9/R6,R10：桌面/小屏与键盘、活动检查及滚动行为有实际验收；LiveView/核心回归、资产构建和安全检查通过或如实记录阻碍；开发 dashboard/debugger 不扩大暴露。实际本地浏览器走查（geckodriver+Firefox 158，确定性宿主）34 项通过/1 项受阻/0 项失败：1440px 与 500x758 内部视口无横向溢出、条件环境、预设切换/调整/重置、Enter 提交创建、真实模型→工具→模型与第二 turn、实时活动卡、子检查器仅观察、向上阅读不被强制滚动且新活动按钮可回到底部、19 个可见焦点停靠点、离开后重新发现、stop 保留/close 确认后结束、三个管理页与 CSP 转义。受阻项：390px 视口（Firefox 本机最小 500 CSS px，四次尝试均被钳制）、浏览器 console 日志 API（驱动 405）与浏览器内 busy/多观察者冲突；未宣称触控、读屏、对比度、缩放或真实断网重连。
- [x] AC10/R10：Web opt-in 组合覆盖本地三角色和 interaction-only 远程模式；普通 umbrella 加载无角色/网络/provider 副作用，既有 CLI/daemon 闭包与默认 Agent 订阅保持兼容。

## Out of Scope

- 数据库、持久化、durable action、历史重放、存档、失效 Agent 恢复/迁移和自动业务重试。
- 账号/SSO/多租户/RBAC；企业包装不被宣传为已有资源隔离。
- Preset 在线编辑/市场/导入执行代码、系统提示词编辑器、新模型协议、写文件/Shell/沙箱等新工具实现。
- 工作流/多 Agent 拖拽画布、模型自行委派能力、人工逐次审批协议。
- 集群部署/远程终端/任意 RPC/热配置/角色切换、完整 trace/metrics 存储与导出。
- 新 Web release 打包、付费模型调用和物理多主机验收；既有 release 回归按实际影响范围执行。

## Risks and Deferred Items

当前快照不足以承载目标 UI，需要先完成有界公共投影；它不承诺完整历史。内存上下文、订阅和实例容量仍受现有上限约束。未来持久性由 durable action 另行提供，不能借本任务引入影子存储。没有阻塞产品问题；拟议 API 与数值上限属于本轮技术设计，仍待最终文档审阅。
