# 完善中文文档与代码注释

## 目标

建立准确、可导航的中文文档及源码说明，使使用者能运行项目、维护者能理解契约与关键约束。

## 背景和共同范围

父任务为 `../10-19-bilingual-documentation/`。共同需求、证据与约束以其 `prd.md` 为准；生产范围为十三个应用、148 个源文件及父任务覆盖清单中的文档入口。独立文档使用 `_zh.md` 中文文件；用户在中文阶段完成后放弃英文阶段。

## 要求

- 补齐根目录与十三个应用的中文 README，核对术语表、当前架构/持久化说明、Web 专题及部署使用文档。
- 逐源文件阅读并补充公开模块、函数/宏/回调和公开类型说明；为关键时序、持久化、资源归属和不重试逻辑补必要注释。
- 更新共同覆盖清单，列明具体模块/API、依据及无需改动的理由；维持 `@doc false` / `@moduledoc false`。
- 只改文档和解释性注释；不改签名、类型、行为、配置值、产品翻译、依赖或历史资料。
- 源码先完善中文，保留已有有效英文；不生成尚未创建目标的断链。英文阶段已由用户撤销，不再补齐。

## 顺序依赖

本任务是唯一实施任务，依赖父任务最终规划获用户明确批准。不得同步编写新的英文版本；既有有效英文内容保留。

- [x] 父任务 AC1–AC3 所属的中文文档入口、公共契约及源文件审阅记录完整，不以机械编辑计数替代语义审阅。
- [x] 父任务 AC4：形成独立的中文完成基线和 verification.md，并已报告完成。
- [x] 父任务 AC5：中文文件路径遵循 _zh.md，术语/标识符清晰，保留关键错误及执行约束。
- [x] 父任务 AC6–AC7：适用检查结果可追溯，AST/差异确认无行为变化，失败或环境限制未记作通过。
