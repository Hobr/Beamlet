## Verified findings and repairs

1. **Configurable byte boundaries were missing.** Added validated `operation_bytes`, `result_bytes`, `progress_bytes`, `report_bytes` deployment options. Defaults remain conservative protocol ceilings (256 KiB, 1 MiB, 8 KiB, 64 KiB); overrides range from 1024 to the corresponding ceiling. Submit and executor revalidate full Operation descriptions; producer, gateway and sink progress envelopes are bounded; gateway completion and sink Result envelopes include transport identity/metadata in size checks. Overflow is explicit and cannot silently truncate executable input. Regression uses values below protocol ceilings but above deployment caps.
2. **Trusted registration and Directory replies were insufficiently bounded/typed.** Added Report validation: counts, UTF-8 labels, handler callback availability, settings size, provider PID shape, positive pool units and a startup report-overhead allowance. Reports contain only explicit public fields; settings/providers stay local. Directory rejects malformed, oversized and unknown-key reports before caching. Node/gateway/incarnation/readiness/pool/handler/utilization fields are checked. Discovery bounds the union of cached and pending endpoint identities, including join notifications.
3. **Discovery relied on polling.** Directory now subscribes to pg group monitoring, queries joins promptly, monitors endpoint PIDs and invalidates leave/DOWN reports/pending queries. Periodic nonce refresh/local-clock expiry remain. Coupled shared restart handles scope loss/re-registration without business replay; independent execution composition remains usable. Tests establish membership leave invalidates the cache while the endpoint stays alive and refresh is ten seconds away.
4. **Auxiliary progress was delayed until handler return.** A task-owned linked, monitored marshaler forwards live while the synchronous handler runs. Producer credits/count/rate still bound attempted messages; all producers use this one marshaler stream. Wrapper completion flushes it; worker/coordinator/gateway loss ends owned helper work. Tests observe progress with result still nil, and explicitly monitor helper/worker death on coordinator and gateway loss. Arbitrary handler-created unlinked processes/external resources remain handler responsibilities.
5. **Coordinator dispatch and message acceptance were too permissive.** Dispatch runs only for a live, unstopped, undispatched coordinator. Admission/progress/completion check the exact advertised gateway and incarnation; completion additionally checks accepted handle, operation/execution IDs and execution source. Result.valid? now requires bounded binary IDs, a nonnil execution ID for execution-origin data and plain-map metadata. Metadata is revalidated after coordinator observation fields merge, with safe bounded overflow normalization. Duplicate/late messages cannot overwrite accepted Results or re-dispatch terminal work.
6. **Repeated cancellation created extra timers; unrelated crashes could become cancellation.** Coordinator cancellation is idempotent, and an atomic gateway token schedules shutdown/escalation once. Gateway records whether it issued kill escalation. Only observed shutdown or its own escalation can produce worker_stopped; unrelated killed-worker crashes remain worker_lost even after the cancellation request. Racing valid success stays success. This is an observation of process termination, never proof of external rollback.
7. **Task-supervisor start failure could crash Gateway.** Admission catches startup failure and returns a definite capacity rejection/tombstone before resource charging; the regression forces worker-supervisor capacity exhaustion and verifies gateway identity/accounting survives.
8. **Tombstone saturation lacked regression proof.** Saturated tables invalidate prior leases through a rejection watermark. A test completes the sole tracked attempt, forces an unrecorded rejection, waits for actual tombstone expiry, redelivers the original rejected envelope and confirms ineligibility/no worker/no charge. Additional multi-pool/duplicate completion tests prove atomic charge and single release.
9. **Queued admission could outlive the submitted duration.** Executor subtracts report-lease age using only its own monotonic clock before admission and starts its execution timer with the reduced duration. This conservatively includes report age as well as queue/transport delay; old snapshots can shorten a short budget. It avoids comparing clocks across machines and never adds a retry.
10. **Generic text validation overrejected leading slashes.** Slash-prefixed UTF-8 text is now ordinary data; rejecting all such strings breaks generic text and future native provider results without proving root secrecy. Conventional secret/root/workspace_root keys remain forbidden, and executor roots must stay local. Producers still own semantic redaction of roots/secrets embedded in arbitrary prose. This is documented explicitly, with regression coverage.
